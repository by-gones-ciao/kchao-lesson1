# K-Chao 초급1 · 1과 1차시 — 화면별 전체 메타데이터

출처: `[변경안] 1차시 학습 flow(0830).pdf` (32p)
목적: 각 화면을 구성하는 **모든 이미지 · 모든 텍스트(KR/VI 원문) · 모든 음원 · 모든 상호작용**을 빠짐없이 목록화.

범례
- `IMG` 이미지 · `TXT` 텍스트 · `AUD` 음원 · `ACT` 상호작용/전이
- 텍스트는 PDF에 보이는 문구 그대로 전사. `…` 는 말풍선/영역에 가려 잘린 부분.
- `[신규]` = 현재 `src/lessonData.js` 에 없는 데이터.

## 전역 규칙
- **모든 "시작 화면"·"소개 화면"에는 베트남어 음성 안내가 자동 재생된다** (화면 진입 시 1회). 대상: 학습 목표(튜터 안내), 단어 학습 시작, 단어 소개(각 슬라이드), 문법 학습 시작, 실전 학습 시작, 실전 각 파트 튜터 안내, 완료·격려 화면 등. → 각 화면에 `aud.*_vi` (베트남어 내레이션) 필드 필수.
- 튜터 캐릭터(핑크 가디건/금발 묶음) = `assets/practice/tutor.png` 계열. 안내·격려 발화 주체.
- 말풍선에는 대개 스피커 아이콘(다시 듣기)이 있고, 화면에 따라 지구본 아이콘(VI 자막 토글)이 있다.
